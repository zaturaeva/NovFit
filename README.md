# NovFit

Приложение для дневника активности на Vue 3 + Vite с API на Express, SQLite и чатами в реальном времени через WebSocket.

## Требования

- Node.js 22.18+ (или Node.js 24.12+)
- npm

## Запуск

```bash
npm install
npm run dev
```

Команда запускает API на `http://localhost:3001` и клиент Vite на `http://localhost:5173`. Vite проксирует `/api` и `/ws` на API-сервер. База SQLite создаётся автоматически в `server/data/novfit.sqlite` при первом старте.

Для production-сборки клиента: `npm run build`. Сервер запускается отдельно командой `npm run server`.

## Реализовано

- Регистрация с именем, уникальным никнеймом, почтой и паролем; вход по почте и паролю.
- JWT-аутентификация API и защита маршрутов клиентского приложения.
- SQLite-хранение пользователей, записей дневника, дружбы и сообщений.
- Добавление воды, сна, питания и активности на главной странице; изменение целей воды и сна.
- Загрузка данных дневника с сервера; кольца воды, питания и активности обновляются после сохранения.
- Поиск людей по никнейму, отправка заявок, принятие и отклонение входящих заявок.
- Чат с друзьями через WebSocket; история сообщений загружается из SQLite.
- Сохранение приёмов пищи и упражнений со страницы дневника.

## Конфигурация

Можно задать `PORT` и `JWT_SECRET` в окружении. Для реального развёртывания обязательно задайте длинный случайный `JWT_SECRET`, настройте HTTPS/WSS и ограничьте CORS разрешённым доменом.
